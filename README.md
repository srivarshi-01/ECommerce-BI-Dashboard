# E-Commerce Business Intelligence Dashboard

An interactive dashboard developed using Python, Streamlit, and Pandas to analyze e-commerce sales data and generate business insights.

## Live Dashboard

[Click here to view the E-Commerce BI Dashboard](https://ecommerce-bi-dashboard-tc4ydqrnyeuyfdw9ehtybm.streamlit.app/)

## Technologies Used
- Python
- Streamlit
- Pandas

## Features
- Sales and revenue analysis
- Profit analysis
- Product performance analysis
- Customer behaviour analysis
- Payment method analysis
- Interactive filters and downloadable reports
